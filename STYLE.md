# Our coding style 
- Use meaningful variable names: use  user_name  instead of  a 
- Keep each function only do one task: a function just prints greeting, not calculate and print together
- Add short comments only for confusing logic, do not comment obvious code
- Indent code with 4 spaces every time, keep indent consistent
- Keep line length short, do not write very long code in one line
- Separate different code blocks with blank lines for readability
- Write simple output prompts, for example  print("Hello, welcome!")
